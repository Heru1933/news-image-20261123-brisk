The Wire — a compact tabular front page for Monday 23 November 2026. 36 stories, all verified against Reuters, AP, BBC, ESPN, Sky, Fox News, PTI, AFP, UKMTO, UN, WHO, Arab News and Al Jazeera, each with its source noted. Pure Python standard library renderer (no Pillow): a 5x7 bitmap font, a small canvas, and a PNG encoder, drawing a navy masthead, a COP31 hero with an overtime bar, two second-row features, a numbers strip, a two-column wire table of 33 stories, and a by-region count.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) to `MAKEFUN_OUTPUT_DIR` when set, otherwise to `output/`.
